# Assignment 6 - jQuery

This project contains jQuery tasks about selectors, effects, DOM manipulation, and animations.

## Pages

- index.html - jQuery Setup and Selectors
- effects.html - Visibility, Fade, and Slide Effects
- dom.html - DOM Manipulation and Form Interaction
- animations.html - Basic, Sequential, and Combined Animations
- project.html - Interactive Accordion Menu

## Technologies

- HTML
- CSS
- JavaScript
- jQuery

## Features

- jQuery selectors
- Changing text, HTML, and CSS
- Show, hide, and toggle effects
- Fade and slide effects
- Adding and removing elements
- Modifying attributes
- Live form interaction
- Basic and sequential animations
- Combined animations
- Interactive accordion menu

## How to Run

1. Download or clone the repository.
2. Open index.html in a browser.
3. Make sure you have an internet connection for jQuery CDN.
4. Use the navigation bar to open different pages.
